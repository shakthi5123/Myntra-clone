# Myntra-clone

This Myntra Clone is a front-end web project designed to replicate the look and feel of the popular Indian e-commerce fashion platform, Myntra. Built using HTML, CSS, and a touch of JavaScript, the clone includes key sections such as a responsive navigation bar, hero banners, product listings, and a structured footer. The design aims to mirror Myntra’s user-friendly interface and layout, giving users a familiar browsing experience. The navigation bar includes features like search, profile, wishlist, and bag icons, styled to closely resemble the original site.

The project includes basic responsiveness to ensure usability on both desktop and mobile devices. Elements such as images, text blocks, and buttons adjust to screen sizes using flexible layouts and font scaling. While not fully mobile-optimized with advanced CSS techniques
